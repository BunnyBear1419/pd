# Stage 11 — Interior Architectural Finish Accents

Adds lightweight interior visual details in a dedicated collection, leaving the earlier structure and furnishing collections intact.

## Files
- `generate_stage11_interior_details.py` — Blender generator.
- `INTERIOR_FINISH_AND_CLEARANCE_CHECKLIST.md` — review and optimization checklist.

## Run order
1. Open the project scene and run Stages 2, 3, and 4 first.
2. Run this script in the same Blender scene.
3. Inspect `PDHQ_INTERIOR_ARCHITECTURAL_DETAILS`.
4. Re-run safely after edits; only this stage's collection is cleared.

## Included details
- Corridor skirting and thin accent rails
- Lobby reception feature wall with slats and a welcome label
- Dispatch backdrop and label
- Evidence/armory visual markers
- Detective floor wall panels
- Simple stair-core wall-protection strips

## Important
Coordinates are provisional, based on the current blockout. Inspect for overlaps with walls, glazing, doors, furniture, and signs. This pass does not implement working doors, access control, final textures, UVs, collision, LODs, portals, occlusion, or Sollumz metadata. Run the Stage 5/6 checks and validate the real export in FiveM before production use.
