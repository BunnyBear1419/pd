# Stage 6 — Layout validation checklist

## Before running
- [ ] Run Stage 2, Stage 3 and Stage 4 in that order, in one Blender scene.
- [ ] Save a working `.blend` copy before detailed edits.
- [ ] Run Stage 5 scene audit and Stage 6 layout validation.

## Human review
- [ ] Confirm public entrance connects to reception and booking.
- [ ] Confirm secure holding/cells are separated from public circulation.
- [ ] Confirm garage is connected to the intended vehicle route without blocked bays.
- [ ] Confirm dispatch, evidence, armory and SWAT zones have appropriate controlled access.
- [ ] Confirm detective workstations and interview rooms have sensible circulation.
- [ ] Confirm roof access, parapets, helipad approach, and HVAC service paths.
- [ ] Check stairs and elevator shaft against slab openings; these are only placeholders in the current model.
- [ ] Review and remove duplicated Stage 2 / Stage 3 interior partitions.
- [ ] Hide/delete guide empties and yellow garage clearance boxes before final asset export.

## Gate before production export
Do not proceed to a release build until room geometry, walkable surfaces, collision, door openings, material/UV plan, LOD plan, Sollumz metadata, and FiveM in-game tests have been reviewed.
